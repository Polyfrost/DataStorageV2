# HitColor X

OneClient already ships DamageTint, which changes the hit color. HitColor X also crashes the game on startup with "Duplicate bind name Sampler1" when installed next to CookeyMod, because both mods add the same sampler to the armor render pipeline. CookeyMod already has its own hit color option. Use DamageTint or CookeyMod's hit color instead.
